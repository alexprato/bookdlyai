APsurance widget — local preview

This page mounts the widget so you can test the full flow before deploying. Look for the chat launcher in the bottom-right corner. Open it, run through both paths (Check if I qualify and Talk to Alex), and watch the browser console — when no webhook is configured, the captured lead is logged there as [APsurance lead — no webhookUrl configured].

To test webhook delivery, set webhookUrl in the config block below to a real endpoint (try a free webhook.site URL).
